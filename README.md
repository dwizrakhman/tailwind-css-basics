# Tailwind CSS Basics

A collection of hands-on exercises and responsive UI components built with Tailwind CSS, covering utility-first styling, CSS-to-Tailwind conversions, and Flexbox/Grid layouts.

## 📋 Table of Contents

- [Topics Covered](#topics-covered)
- [Project Structure](#project-structure)
- [How to Run](#how-to-run)

## 📚 Topics Covered

- **Utility-First Fundamentals:** Setting up Tailwind CSS via CDN and styling elements with spacing (`p-*`, `m-*`), typography, color palettes, borders, and rounded corners.
- **CSS-to-Tailwind Conversion:** Refactoring traditional manual CSS stylesheets into clean, inline Tailwind utility classes.
- **Responsive Layouts:** Building mobile-first layouts using Flexbox (`flex-col`, `md:flex-row`) and CSS Grid (`grid-cols-1`, `sm:grid-cols-2`, `lg:grid-cols-3`).
- **UI Components:** Creating responsive profile cards, product card grids, and an interactive mobile navigation bar.

## 🚀 How to Run

1. Clone or download this repository:
   ```bash
   git clone https://github.com/dwizrakhman/tailwind-css-basics.git
   ```
2. Open the project folder in **Visual Studio Code**.
3. Right-click any `.html` file and select **Open with Live Server** (or open it directly in your browser).
4. Resize the browser window or use **Browser DevTools** (`F12`) to test the mobile, tablet, and desktop responsive breakpoints.
